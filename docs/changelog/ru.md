# Список изменений

Русская версия [CHANGELOG.md](../../CHANGELOG.md). Раздел версии показывается в «О программе» как заметки к обновлению.

## 0.1.0
Первая версия Glafira for LLM Inference — настольного приложения для корпоративного инференса open-source LLM во внутреннем контуре; в фокусе — vLLM и SGLang. В этой версии — подключение, проверка и мониторинг; диагностика и аудит появятся в следующих версиях.
- Инсталляции:
  - инсталляция объединяет серверы инференса одной системы: vLLM, SGLang или любой OpenAI-совместимый сервер;
  - адреса `http://` и `https://`, системное хранилище CA, только указанные сертификаты или без проверки (если это разрешает политика), системный или явный прокси;
  - ключи API хранятся только в системном хранилище секретов;
  - папки, перетаскивание, экспорт и импорт без ключей.
- Пошаговая проверка сервера: конфигурация, DNS/TCP, TLS, `/health`, ключ API, тип и версия, модели.
- Вкладка инсталляции: у каждого сервера — тип и версия, модели с длиной контекста и адаптерами LoRA, наличие метрик и ошибки.
- Вкладка сервера: метрики из `/metrics` раз в 5 секунд, пока вкладка открыта (запросы в работе и в очереди, KV-кэш, токены в секунду, перцентили TTFT и ITL, вытеснения), аргументы запуска с источником и графики за последний час.
- История метрик из Prometheus или VictoriaMetrics, который уже опрашивает серверы: окна от часа до 30 дней, сопоставление серверов с пошаговой проверкой; сама Glafira ничего не хранит.
- Карты NVIDIA по метрикам DCGM (dcgm-exporter напрямую или через Prometheus): утилизация, активность SM, память, температура, мощность, такты и признаки проблем (троттлинг, XID, ECC, NVLink, повторы PCIe) по хостам и картам, с графиками.
- Вид под macOS: заголовок окна слит с боковой панелью и панелью вкладок, системный акцент и цвета macOS в обеих темах, единое дерево со значками и направляющими, пункт активной вкладки подсвечен, значки вместо символов текста. Клавиатура: ⌘N новая инсталляция, ⌘W закрыть вкладку, ⌘R обновить, ⌘F поиск, ⌘1…⌘9 и ⌃Tab переключение вкладок, ⌘, настройки; на macOS — в меню приложения, на Windows и Linux те же с Ctrl. Окно запоминает размер и положение.
- Тексты запросов и ответов ваших пользователей Glafira не читает и не показывает.
- Обновления из «О программе» → «Обновления» с проверкой подписи. Установщики для macOS (приложение подписано и нотаризовано Apple), Windows и Linux.
- Руководство на английском и русском.
